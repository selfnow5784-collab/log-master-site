Install Log Master

Open the app, then install it so it works like other apps on your device. After that, it works offline.

Install Log Master
  1. 1iPhone (Safari): tap Share, then Add to Home Screen.
  2. 2Android (Chrome): open the menu, then tap Install app.
  3. 3Computer (Chrome or Edge): click the install icon in the address bar.
