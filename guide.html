User Guide

How to use Tool Shelf

Five steps to install the app, load your catalog, and look up items.

  1. Open the app

    Go to the live app, or follow the install steps on the Downloads page so Tool Shelf sits on your home screen or computer. After it is installed, it works offline.

  2. Import a CSV catalog

    Tap Data at the top, then Import new CSV, and choose a CSV file from your device.

  3. Confirm the import

    If a catalog is already loaded, the app asks Replace the loaded file? You can save a copy first, replace without saving, or cancel.

    If the app asks What is this file?, choose the kind of file (for example Reference catalog), check the Import preview, and tap Import.

    The Data tab then shows the loaded file name and row count.

  4. Search your list

    Switch to the Reference tab and type in the search box to find items. Tap a row to open its details.

    On a computer, File / Edit / View / Help is at the top. On a phone, the ☰ button opens the same menu. File has Print and Share (PDF) of the current view. Edit lets you add your own item or hide selected rows. Filters and columns are under View.

  5. Export or unload the file

    On the Data tab, use Export catalog to download a copy, or Empty to unload the file. Your in-stock list, your own items, and settings stay on the device. Your catalog is stored on this device, in your browser — it is not uploaded to this website.
