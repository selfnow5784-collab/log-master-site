# How to edit the Tool Dude website

The site is plain files. Each page is one file:
- index.html: Home
- downloads.html: Downloads
- guide.html: User Guide
- faq.html: FAQ
- contact.html: Contact
- css/styles.css: colors, fonts and look (teal is #00b3a4)

## Change text on GitHub (no tools needed)
1. Sign in at github.com and open this website's repository.
2. Click the page file, for example contact.html.
3. Click the pencil icon (Edit).
4. Change only the words between the tags, e.g. `<p>your text</p>`.
5. Click "Commit changes". The live site updates in 1-2 minutes.

## Add a picture or file
Click "Add file", then "Upload files", drop it into the assets folder, and commit.

## Host it somewhere else
These files work on any free static host (GitHub Pages, Netlify, Cloudflare Pages). Upload the folder as it is.
